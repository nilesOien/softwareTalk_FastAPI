Other frameworks, other languages

FastAPI is a Python API framework. There are other Python frameworks, and other frameworks in other languages.

I coded a very simple server in both Python's FastAPI and Rust's Actix Web and compared the two. The Python one ran in about 3 seconds, the Rust one ran in about 4. When Postgres was the database instead of sqlite, the Rust one was slightly faster than Python.
