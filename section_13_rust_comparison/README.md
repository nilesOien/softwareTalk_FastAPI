# Section 13 : Rust versus Python

Rust has to be installed to do this. I suspect most folks I know
will skip it.

Both the Rust and the Python servers must be running.
Instructions are in the Rust/ and Python/ directories.

With those servers running, the runPyRustTest.sh script
can be run. All it does it dump the H-Alpha database using
both the Rust and Python servers, printing the fetch time
in seconds.

Bottom line is that I found Rust and Python comparable, with no significant
difference in speed.

Notice that Python is hardly the only language to have an
API framework. Almost all modern languages do.
