
# Section 8.0

This is a repeat of section 7.0 except that instead of assembling
SQL strings to talk to the database, we use the ***sqlAlchemy***
Object Relational Mapping (ORM) system.

The steps are :

* Run **installPackages.sh** to install the packages
* Run **startServer.sh** to start the server
* Look at the served out JSON at http://127.0.0.1:8008/static-dict
* Look at the code in demoFastapi.py to see the ORM
