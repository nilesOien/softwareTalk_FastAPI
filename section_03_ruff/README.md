# Section 3.0 : The ruff python checker

The goal is to understand ruff. Things to do :

* Run **installPackages.sh** to install the ruff package
* Run **uv run ruff check** to see it go
* Optionally, run **cleanup.sh** to clean up

Understand that ruff exits with zero exit status only if
everything is fine (not unusual, but relevant for section 6).
