Not the only way to write an API :

  • https://gong2.nso.edu/products/latestProducts/zqa.php gets the latest zqa magnetograms - written in PHP
  • https://gong2.nso.edu/products/latestProducts/iqa.php same thing for intensity data
  • https://gong2.nso.edu/products/hAlphaLatest/hac.php Similar for H-Alpha
  • Our existing movie pages use this which uses XML not JSON

FastAPI isn't perfect. If end points start proliferating, it may be better to use GraphQL.
