# Section 12.0

The server from section 9.0 must be running for this to work.

This demostrates a javaScript web client running in a browser.

The javaScript queries the API to get the URLs for data files, then
modifies the URLs so that they point to the image files rather than
the data files, and then displays them in a simple movie player.

That can be viewed in display.html and it is best to put your
browser into debug mode (keystroke F12 for Chrome).
