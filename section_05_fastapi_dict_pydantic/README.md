
# Section 5.0

This demostrates the basic idea of FastAPI **with
the addition of Pydantic**. Python
structures are served out as JSON **but with validation**.

The steps are :

* Run **installPackages.sh** to install the packages
* Run **startServer.sh** to start the server
* Look at the served out JSON at http://127.0.0.1:8004/static-dict
* Look at the swagger documentation at http://127.0.0.1:8004/docs
* And more documentation in a different style at http://127.0.0.1:8004/redoc
* Optionally run cleanup.sh to clean up

Notice that now the documentation can tell you what the end point will deliver.
