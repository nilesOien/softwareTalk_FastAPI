# Section 10.0

The server from section 9.0 must be running for this to work.

This is a demo of getting the listing of H-Alpha files for a
range of sites and a range of time and downloading them.

The steps are :

* Run **installPackages.sh** to install the packages
* Run **runDemo.sh** to do the downoload by running **downloadClient.py** with appropriate arguments
* Optionally run **cleanup.sh** to clean up.

Notice how the command line arguments are parsed in downloadClient.py which is a python standard.
